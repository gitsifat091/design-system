# Badge

Short status labels in tables, cards and headers.

**Provide:** one or two words in sentence case. The tone class sets the color pair: neutral (default), `ii-badge-brass`, `ii-badge-success`, `ii-badge-warning`, `ii-badge-danger`, or `ii-badge-outline`.

- Each tone is text color on its `-soft` ground (for example `success` on `success-soft`), 5:1 or better in both themes.
- The dot plus the word carry the meaning; never rely on color alone. Use `no-dot` for version tags and counts.
- Radius `radius-sm`, height 22px, `label`-style text at 12px.
