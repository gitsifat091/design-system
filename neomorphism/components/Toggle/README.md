# Toggle

A sunken pill track with a raised knob; the track fills with `accent` when on.

- Built on a native checkbox inside a `<label>`, so keyboard and screen readers work.
- The knob position, not only the colour, carries the state.
- The track carries a 1px `line` outline: surface on surface-sunken alone is about 1.2:1, too faint to find the control.
